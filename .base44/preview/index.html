پیش‌نمایش اپلیکیشن اندروید (Jetpack Compose)

این اپلیکیشن یک برنامه‌ی نیتیو اندروید است و در مرورگر اجرا نمی‌شود؛ همین‌طور سندباکس، شبیه‌ساز اندروید (KVM) ندارد. برای همین، صفحات برنامه از کد واقعی app/src/main به‌صورت هدلس رندر شده‌اند (Robolectric + Roborazzi روی پروفایل Pixel 8، API 36) و فایل APK ساخته‌شده هم برای نصب روی گوشی در دسترس است. داده‌های نمایش‌داده‌شده نمونه هستند.
This is a native Android app, so the browser preview shows its real Compose screens rendered headlessly (no emulator in the sandbox) plus the built APK.
