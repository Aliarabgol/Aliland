# راهنمای مدیر نمایشگاه

این راهنما برای استفاده از پنل مدیریت وب‌اپ نمایشگاه است.

## ورود

- نشانی پنل: `/admin/login`
- حساب‌های نمونهٔ توسعه (فقط برای آزمایش):
  - مدیر: `admin@showroom.local` / `admin1234`
  - کارشناس فروش: `sales@showroom.local` / `sales1234`

پیش از استفادهٔ واقعی، گذرواژه‌ها را تغییر دهید و حساب‌های واقعی را از بخش «کارکنان» بسازید.

## افزودن خودرو

۱) پنل → «خودروها» → «افزودن خودرو».
۲) اطلاعات اصلی، مشخصات، قیمت و توضیحات را پر کنید.
۳) وضعیت موجودی (موجود/رزرو/فروخته/خارج‌شده) و وضعیت انتشار (پیش‌نویس/در انتظار/منتشرشده/بایگانی) را جدا تعیین کنید.
۴) برای نمایش در سایت، وضعیت انتشار باید «منتشرشده» باشد و موجودی «موجود» یا «رزرو».
۵) اطلاعات خصوصی (مالک، قیمت خرید، کمیسیون، یادداشت داخلی) فقط برای مدیر نمایش داده می‌شود و هرگز عمومی نیست.

## گزارش کارشناسی، تصاویر

- گزارش عمومی فقط نسخهٔ پاک‌سازی‌شده است و اطلاعات هویتی مالک را ندارد.
- در نبود عکس واقعی، کارت‌ها تصویر نمونه با برچسب «تصویر نمونه» نشان می‌دهند.
- ثبت عکس مهمان در این نسخه غیرفعال است؛ عکس‌ها در پیگیری امن پس از تماس دریافت می‌شوند.

## انتشار، تغییر قیمت و وضعیت

- «انتشار» و «لغو انتشار» از فهرست خودروها در دسترس است.
- قیمت نامشخص را با حالت «تماس برای قیمت» ثبت کنید (نه صفر).
- فروخته‌شده و خارج‌شده به‌صورت پیش‌فرض در موجودی عمومی نمایش داده نمی‌شوند.

## پیگیری درخواست‌ها

- پنل → «درخواست‌ها». درخواست‌های بازدید، تماس، فروش، درخواست خودرو و پیام تماس اینجا ثبت می‌شوند.
- وضعیت را تغییر دهید (جدید، تماس گرفته شده، هماهنگ شده، موفق، ناموفق، بسته).
- مدیر می‌تواند درخواست را به کارشناس واگذار کند. کارشناس فقط درخواست‌های خودش یا بدون واگذاری را می‌بیند.

## مدیریت کارکنان

- پنل → «کارکنان» (فقط مدیر). افزودن کارمند، تغییر نقش و فعال/غیرفعال کردن.

## خروج از حالت demo

- پنل → «تنظیمات» → «حالت اجرا» را به «واقعی (live)» تغییر دهید، پس از آنکه اطلاعات تماس و داده‌های واقعی تکمیل شد.
- داده‌های نمونه با برچسب «نمونه» از آمار واقعی جدا می‌مانند.

## اتصال‌ها

- پیامک، نقشه و پیام‌رسان تا زمان ارائهٔ سرویس و فعال‌سازی مدیر غیرفعال هستند.
- شماره، آدرس یا لینک تماس واقعی را فقط پس از ثبت دادهٔ درست در تنظیمات قرار دهید؛ تا آن زمان لینک تماس مستقیم نمایش داده نمی‌شود.

## نکات امنیتی

- دادهٔ خصوصی (لیست درخواست‌ها، اطلاعات مالک، فایل خصوصی) از طریق API عمومی قابل دسترسی نیست.
- نشست پنل با کوکی HttpOnly مدیریت می‌شود؛ خروج از پنل نشست را پاک می‌کند.
